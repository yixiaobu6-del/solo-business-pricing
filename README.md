# 一人公司定价决策器

定价凭感觉？
**数据驱动的定价分析帮你找到最优价格。**

[![HTML](https://img.shields.io/badge/打开即用-无需安装-orange)]()

## 定价不再"拍脑袋"

- **敏感度分析**：弹性模型，Chart.js双Y轴曲线
- **组合定价**：捆绑+订阅分层，多产品策略
- **竞品对标**：市场价格参考，定位决策
- **利润模拟**：不同定价方案利润对比

## 怎么用

打开 `index.html` → 输入成本和竞品价格 → 查看建议
